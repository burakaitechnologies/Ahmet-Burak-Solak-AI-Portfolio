# L05 - CNN Chihuahua vs Muffin Classifier

## Problem Statement

This lab trains a convolutional neural network to distinguish between visually similar image categories.

## Approach

The notebook prepares the dataset, defines image transformations, builds a CNN, trains the model, evaluates performance, and visualizes predictions.

## Results and Key Findings

The reflection reports about 85% validation accuracy and explains how CNN layers preserve image structure better than fully connected networks on flattened pixels.

## Technologies Used

- Python
- PyTorch
- Torchvision
- CNNs
- Jupyter Notebook

## How to Run

Open the notebook in Google Colab or Jupyter and run all cells. The reflection PDF is included for the written analysis.
