# L10 - Building an Agent with a Framework

## Problem Statement

This lab explores how AI agents use tools, memory, and reasoning loops to solve tasks across multiple steps.

## Approach

The notebook builds simple tools, stores conversational memory, implements a reasoning loop, and compares framework-based agents with from-scratch implementations.

## Results and Key Findings

The work shows why memory helps agents preserve context, why tools extend model capability, and how reasoning loops coordinate decisions.

## Technologies Used

- Python
- Agent framework concepts
- Tool calling
- Memory
- Jupyter Notebook

## How to Run

Open the notebook in Google Colab or Jupyter and run all cells.
