# L08 - Visual Language Models

## Problem Statement

This lab studies models that connect images and text, such as CLIP-style visual language models.

## Approach

The notebook explores image/text embeddings, zero-shot classification, image search, contrastive learning, fine-tuning concepts, deployment trade-offs, and VLM limitations.

## Results and Key Findings

The work shows how VLMs compare visual and language representations and why they are useful for image search, classification, and multimodal reasoning.

## Technologies Used

- Python
- CLIP/VLM concepts
- Embeddings
- Similarity matrices
- Jupyter Notebook

## How to Run

Open the notebook in Google Colab or Jupyter and run cells in order.
