# L03 - Classical Machine Learning for Computer Vision

## Problem Statement

This lab studies how classical machine learning can classify images when raw pixels are converted into useful features.

## Approach

The notebook uses face image data, train/validation/test splits, HOG features, Local Binary Patterns, model training, overfitting demonstrations, and final evaluation.

## Results and Key Findings

The lab demonstrates why feature extraction matters and how validation/testing prevents misleading model performance.

## Technologies Used

- Python
- scikit-learn
- scikit-image
- NumPy
- Matplotlib
- Jupyter Notebook

## How to Run

Open the notebook in Google Colab or Jupyter and run all cells in order.
