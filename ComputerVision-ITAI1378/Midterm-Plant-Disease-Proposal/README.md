# Midterm Proposal - Plant Disease Detection System

## Problem Statement

Farmers can lose major crop yield when plant diseases are detected too late. A computer vision system can help identify disease signs from leaf photos more quickly.

## Approach

The proposal designs an image classification system that accepts a leaf photo, preprocesses it, runs a transfer-learning model, and returns a disease prediction with confidence.

## Planned Technical Stack

- ResNet50
- PyTorch and torchvision
- Transfer learning
- PlantVillage dataset
- Gradio demo app

## Target Results

- Classification accuracy: 90% or higher
- Inference speed: under 1 second per image
- Per-class precision/recall: 85% or higher
