# A02 - Image Processing Adventure

## Problem Statement

This assignment explains how pixels form digital images and how color models represent image data.

## Approach

The work uses a visual poster-style explanation of pixel grids, image size, RGB color channels, and HSV color representation.

## Results and Key Findings

The project connects visual image appearance to the underlying numeric structure used by computer vision systems.

## Technologies and Concepts

- Pixels and resolution
- RGB color model
- HSV color model
- Image representation
