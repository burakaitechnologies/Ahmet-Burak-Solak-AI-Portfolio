# L06 - Object Detection with Transfer Learning

## Problem Statement

This lab studies object detection, where the system must identify both what objects are present and where they are located.

## Approach

The notebook uses a pre-trained SSD MobileNet V2 model and explores bounding boxes, normalized coordinates, IoU, detection thresholds, and transfer learning concepts.

## Results and Key Findings

The report explains how IoU threshold changes affect true positives, false positives, and false negatives. It also compares classification and detection use cases.

## Technologies Used

- Python
- TensorFlow
- TensorFlow Hub
- OpenCV / visualization tools
- Pascal VOC concepts

## How to Run

Open the notebook in Google Colab or Jupyter and run the cells in order. The PDF report is included for review.
