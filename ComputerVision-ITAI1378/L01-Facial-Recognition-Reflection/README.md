# L01 - Facial Recognition Reflection

## Problem Statement

This reflection explains how facial recognition is used in real-world security and identity systems.

## Approach

The assignment describes how cameras capture a face, how facial landmarks become a digital representation, and how the system compares that representation against stored records.

## Results and Key Findings

The work highlights benefits such as fast authentication and security, while also discussing concerns around privacy, fairness, and accuracy.

## Technologies and Concepts

- Facial recognition
- Computer vision in mobile devices and airports
- Facial landmarks
- Privacy and ethics
