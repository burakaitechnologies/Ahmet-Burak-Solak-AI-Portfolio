# L04 - Neural Network Workshop

## Problem Statement

This lab introduces neural networks for image classification.

## Approach

The notebook follows a workshop-style flow: build the neural network, load image data, train the model, evaluate performance, and visualize results.

## Results and Key Findings

The work demonstrates the basic training loop and the relationship between data, model architecture, loss, optimization, and validation performance.

## Technologies Used

- Python
- PyTorch
- Torchvision
- Jupyter Notebook

## How to Run

Open the notebook in Google Colab or Jupyter and run cells in order. Some cells may download public workshop resources from GitHub.
