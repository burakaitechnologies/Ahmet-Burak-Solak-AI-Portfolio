# L02 - Image Processing Lab

## Problem Statement

This lab explores how computers represent, process, and transform images using numerical operations.

## Approach

The notebook demonstrates image matrices, RGB channels, grayscale conversion, point operations, filtering, histogram enhancement, geometric transformations, and simple artistic effects.

## Results and Key Findings

The lab shows that image effects such as brightness, contrast, blur, sharpening, and edge detection come from mathematical operations on pixel values.

## Technologies Used

- Python
- OpenCV
- Pillow
- NumPy
- Matplotlib
- Google Colab / Jupyter Notebook

## How to Run

Open the `.ipynb` notebook in Google Colab or Jupyter and run the cells from top to bottom. The PDF export and reflection journal are included for review.
