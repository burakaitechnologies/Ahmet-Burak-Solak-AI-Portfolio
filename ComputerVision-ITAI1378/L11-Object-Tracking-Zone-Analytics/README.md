# L11 - Object Tracking and Zone Analytics

## Problem Statement

This lab tracks moving people in video and counts activity across lines and zones.

## Approach

The notebook downloads a public OpenCV sample video, runs object tracking, counts line crossings, creates a rectangular zone, and summarizes zone occupancy.

## Results and Key Findings

The project demonstrates the difference between frame-by-frame detection and tracking across time. It also shows how zone analytics can turn detections into useful activity metrics.

## Technologies Used

- Python
- OpenCV
- Object tracking
- Video analytics
- Jupyter Notebook

## How to Run

Open the notebook in Google Colab or Jupyter and run cells in order. The notebook downloads a public sample video during execution.
